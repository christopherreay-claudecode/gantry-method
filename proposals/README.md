# proposals/ — propositions on the table

One file per proposition. Discussion material: NOT part of the graph until copied into
`plan.md` / `seams.md` / `issues/` (SPEC §6). `../proposals.md` is the extractor's matrix
(`## issues`, `## routes`) and the index of these files.

A proposition file carries the same five headings so they can be compared:
**situation** (what is true today) · **proposition** (the shape) · **lived experience it serves**
(Tier-1 beats, the source of any constraint) · **constraints it would need** (candidates for
plan.md §2) · **open** (what is undecided, and whose call).
